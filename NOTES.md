# Найденные баги и особенности приложения

## BUG-01 — Поля формы регистрации не связаны с label

На странице регистрации визуальные подписи `Name`, `Surname`, `Email`, `Password` отображаются корректно, однако элементы `label` не связаны с соответствующими `input` через `for`/`id`.

### Результат
Для пользователя форма работает, но стандартный доступный способ поиска элемента по имени label (`getByLabel`) в Playwright не работает.

### Влияние
Среднее.

### Обход в автотестах
Для поиска полей используются `placeholder` и CSS-селекторы по типу/имени элемента.

## BUG-02 — Некорректный placeholder у поля Password при регистрации

Поле пароля на странице регистрации отображает placeholder:

`Type your message...`

вместо текста, связанного с вводом пароля.

### Результат
Пользователь может воспринять поле как поле для сообщения, что ухудшает понятность интерфейса.

### Влияние
Низкое.

---

## BUG-03 — Сообщение "All fields are required" недостижимо при обычной отправке формы

В приложении предусмотрена проверка обязательных полей и сообщение `All fields are required`, однако HTML-атрибут `required` блокирует отправку формы браузером раньше выполнения пользовательского обработчика.

### Результат
При нажатии `Register` с пустыми полями пользователь видит стандартное поведение браузера, а предусмотренное приложением сообщение не отображается.

### Влияние
Среднее.

### Проверка в автотесте
Тест проверяет состояние HTML-валидации через `checkValidity()`.
